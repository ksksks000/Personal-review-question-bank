# 📚 题库 · Tiku

> 一个**纯本地运行**的个人面试题库。把散落各处的 markdown 题目文件丢进来，自动切题、归类、去重入库，然后用**间隔重复（SM-2）**帮你按分类刷题、复习、查漏补缺。

无需登录、无需联网、数据全部落在本地 JSON 文件里，随时可整目录备份或迁移。

```
markdown 文件 ─▶ 导入/监控 ─▶ 自动切题 · 归类 · 去重 ─▶ 题库
                                                          │
     今日复习（SM-2）◀─ 掌握状态标注 ◀─ 刷题（先想后看）◀─┴─▶ 搜索 / 筛选 / 批量编辑
```

## 特性

**📥 导入**
- 拖拽 markdown 文件 / 整个文件夹，或点选文件、文件夹；保留目录结构用于自动归类
- 两段式：先解析成预览表（可逐题勾选、改分类、看到重复与「答案有更新」），确认后才入库
- 自动去重（按 `title + 正文` 归一化哈希），重复题默认不勾选，可强制导入
- 导入**更新过答案**的旧题时，默认帮你替换库里旧题的答案，而不是新增一道重复题

**📁 自动导入**
- 开启后可指定一个「监控文件夹」，往里丢 markdown 即自动入库；同名去重、文件改动同步答案

**🗂️ 题库**
- 搜索（可切换「全文」，连题干与参考答案正文一起搜）、按分类 / 掌握状态筛选、分页、排序
- 抽屉式编辑题目内容、分类、标签、掌握状态
- 勾选多选题 → 批量移动分类 / 批量删除

**🎯 刷题**
- 列表浏览式「先想后看」：参考答案默认折叠，点按钮或按空格才展开
- 顺序 / 随机模式；键盘 `←` `→` 翻题、`1/2/3` 标注掌握状态、空格看答案
- 「📕 错题本」一键筛出不熟的题

**🔁 今日复习**
- 基于 SM-2 遗忘曲线自动排程，到期的题进入「今日复习」，侧栏与统计页一键开刷

**📊 统计 · 🏷️ 分类管理 · 🌗 主题**
- 题目总数、掌握进度、今日待复习、分类分布、最近导入记录
- 分类增删改、别名维护（别名驱动导入时的自动归类）
- 日间 / 夜间主题，选择持久化，首帧防闪烁

**🛟 数据安全**
- 启动自动备份（保留最近 10 份）、一键导出完整备份 JSON、从备份恢复

## 快速开始

### 环境要求

- **Node.js ≥ 20**（开发环境在 v24 上验证；Vite 7 需要 20.19+ 或 22.12+）
- Windows / macOS / Linux 均可（本项目在 Windows 11 + 中文路径下重点适配）
- 浏览器：Edge / Chrome（拖拽整个文件夹依赖 `webkitGetAsEntry`）

### 一键启动（Windows 推荐）

双击 **`启动.bat`**：首次会自动安装依赖、启动前后端、打开浏览器；**关闭浏览器页面后约 15 秒**后台自动停止（也可 `Ctrl+C` 手动停）。

### 手动启动

```bash
npm install        # 首次安装依赖（postinstall 会自动装 server/ 和 web/ 的子依赖）
npm run dev        # 开发模式：后端 127.0.0.1:3001 + 前端 http://localhost:5173
```

打开 **http://localhost:5173**。

### 日常使用（生产模式单进程）

```bash
npm start          # 构建前端 + 启动服务，访问 http://127.0.0.1:3001
```

> 生产模式下 Express 单进程同时托管前端构建产物与 API。

## 支持的 Markdown 格式

导入时按以下规则切题与归类，导入页也有同样说明。

**切题**
- 文件含 `## 二级标题` → 每个 `##` 切成一道题，标题即题目名
- 无 `##` → 整个文件算一道题，标题取 front-matter `title` > 首个 `#` 标题 > 文件名

**front-matter（可选）**：文件头部 `---` 包裹，支持 `title` / `category` / `tags`，对文件内所有题生效

**答案分离（可选，按顺序尝试）**
1. 独立的答案标题：`# ~ #### 答案`、`参考答案`、`解答`、`解析`、`回答`、`answer`
2. 行内加粗：`**答案**：`
3. 正文中间的第一个 `---` / `***` / `___` 分隔线（前后都有内容才生效）
4. 都没有 → 答案为空，全文作为题干

**自动归类优先级**：front-matter `category` → 文件名 / 路径命中分类或别名 → `tags` 命中 → 正文前 300 字关键词 → 未分类

### 示例

```markdown
---
tags: [css, 基础]
category: 前端
---

## CSS 盒模型有哪些？

标准盒模型和 IE 盒模型的区别是什么？

---

标准盒模型的 width 只指 content，IE 盒模型的 width = content + padding + border。
可用 `box-sizing: border-box` 切换。
```

## 自动导入（监控文件夹）

在**导入页**的「📁 自动导入」卡片里可以：

- 开关监控、修改监控目录（任意本地文件夹的绝对路径），保存后立即生效
- 查看运行状态：是否监控中、目录内文件数、最近一次事件与新增/更新数量

默认目录是项目下的 `import/`（空目录，不丢文件就不会触发）。把 `.md` / `.markdown` / `.txt` 丢进去即自动解析入库：

- 新题 → 去重后入库
- 已存在但**答案被改动**的文件 → 同步更新库里旧题的答案（不新增重复）

> ⚠️ 指到一个已有大量 markdown 的目录，会一次性把它们都导入进来。

## 复习机制（SM-2）

给题目标注掌握状态时，自动按 **SM-2 间隔重复**算法安排下次复习时间：

| 标注 | 质量分 | 效果 |
|---|---|---|
| `未刷` | — | 无排程 |
| `不熟` | 2 | 重置：下次 1 天后 |
| `已掌握` | 5 | 推进：间隔 `1 → 6 → 上次 × 难度因子`（难度因子 ∈ [1.3, 2.8]） |

- 复习时间到期的题进入 **🔁 今日复习**（侧栏 / 统计页一键开刷）
- **注意**：「已掌握」不是永久封存——间隔到期后会重新出现在今日复习里，用于巩固

## 数据存储与备份

所有数据都在 **`data/`** 目录下的 JSON 文件里，**备份 = 复制这个文件夹**：

| 文件 | 内容 |
|---|---|
| `questions.json` | 全部题目（含复习排程 `review`） |
| `categories.json` | 分类及别名 |
| `import-log.json` | 导入历史（最近 200 条） |
| `config.json` | 自动导入等设置 |
| `backups/` | 启动时的自动快照（保留最近 10 份） |

另有 `import/` 作为默认的自动导入监控目录。`data/` 与 `import/` 均已加入 `.gitignore`，不会进版本库。

### 三重保险

1. **启动自动备份** — 每次启动把 `data/` 快照到 `data/backups/<日期时间>/`；内容没变则跳过，只留最近 10 份
2. **一键导出** — 统计页「⬇️ 导出备份 JSON」下载完整备份文件
3. **备份恢复** — 统计页「↩️ 从备份恢复」选择备份文件，在空题库上还原（恢复前会二次确认）

> 建议把导出的备份文件存到 U 盘 / 网盘等 `data/` 之外的地方，避免本机磁盘一起损坏。

## 项目结构

```
题库/
├─ package.json            # 根脚本 dev / build / start；postinstall 装子包
├─ 启动.bat                 # Windows 一键启动
├─ README.md               # 本文档（使用说明）
├─ 开发文档.md              # 完整技术文档（架构 / API / 实现细节 / 坑位）
├─ 待确认事项.md            # 开发中默认决定的备忘（需用户过目）
├─ import/                 # 默认「自动导入」监控文件夹
│
├─ data/                   # ★ 运行时数据（备份 = 复制本目录）
│  ├─ questions.json
│  ├─ categories.json
│  ├─ import-log.json
│  ├─ config.json
│  └─ backups/
│
├─ server/                 # Express 5 后端（ESM）
│  └─ src/
│     ├─ index.js          # 入口：挂路由 + 生产托管 dist
│     ├─ routes/           # questions / categories / import / stats / review / config / backup
│     ├─ services/         # store(持久化) mdSplit(切题) categorizer(归类) dedupe(去重)
│     │                    # review(SM-2) watcher(文件夹监控)
│     └─ lib/              # ids / fsAtomic(原子写)
│
└─ web/                    # React 19 + Vite 7 前端
   └─ src/
      ├─ pages/            # Library / Practice / Import / Stats / Categories
      ├─ components/       # layout / question / common
      ├─ context/ hooks/ api/
      └─ styles/           # tokens.css(主题变量) global.css
```

**分层约定**：`routes`（HTTP 协议层）→ `services`（业务层）→ `store`（唯一持久化入口）。

## 技术栈

**后端** — Node.js · Express 5 · multer（上传）· gray-matter（front-matter）· marked（词法切题）· nanoid · chokidar（文件夹监控）
**前端** — React 19 · Vite 7 · react-router-dom 7 · react-markdown + remark-gfm + rehype-highlight
**存储** — 本地 JSON 文件（`store.js` 为唯一持久化入口，可无痛替换）
**运行形态** — 纯本地（`127.0.0.1`）、单用户、无登录

## 开发与扩展

- **加后端接口**：`server/src/routes/` 新建路由文件 → `index.js` 挂载；业务逻辑放 `services/`，数据操作只经 `store.js`
- **加前端页面**：`web/src/pages/` 建页面 → `App.jsx` 加路由与侧栏入口
- **换存储引擎**（如超万题换 SQLite）：改 `store.js` 内部实现，保持方法签名，路由与前端零改动
- **改主题色**：只动 `web/src/styles/tokens.css`，组件不写死颜色
- **加分类识别规则**：改 `services/categorizer.js` 的优先级链

> 更深入的架构设计、数据模型、导入管线、启动机制与 Windows 中文路径坑位清单，见 **[开发文档.md](开发文档.md)**。

## 常见问题

**Q：后端只用 `127.0.0.1`，手机/平板能访问吗？**
默认只绑定本机，不暴露到局域网/公网（也避免了防火墙弹窗）。需要跨设备访问时改绑定地址。

**Q：端口被占用怎么办？**
`3001`（API）或 `5173`（前端）被占时，`启动.bat` / 开发启动器会尝试清理本项目残留的孤儿进程；非本项目进程占用则报错退出，不会误杀。（`web/vite.config.js` 设了 `strictPort`，不会静默换端口。）

**Q：为什么刷题页看不到答案？**
答案默认折叠（先想后看）。点「👁 显示参考答案」或按 `空格` 展开。

**Q：导入后题目重复了 / 答案没更新？**
导入按 `标题 + 正文` 去重，重复题默认不勾选；若同一题的新文件**答案有改动**，预览里会标「有更新」，默认帮你替换旧答案。可在预览表里逐题调整。

**Q：`data/` 里的文件被我编辑坏了怎么办？**
从 `data/backups/` 里挑一份时间合适的快照，用统计页「从备份恢复」即可还原。建议平时保留导出的备份文件。

**Q：中文文件名导入乱码？**
已处理（前端额外传编码后的文件名 + 服务端兜底 latin1→utf8 修正），详见开发文档。

**Q：文件夹监控会一直跑吗？**
默认开启但目录为空时不做任何事；可在导入页一键停用。
